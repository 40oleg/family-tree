# Родословная: Илюшкины, Шалагины, Пановы

Интерактивное родословное дерево семьи из Весьегонского края (Тверская и Вологодская области).

Сайт: https://40oleg.github.io/family-tree/

## Обозначения

- **Зелёным** отмечено только новые дополнения исследования 30 октября 2026 г.: люди, места и факты. Прежние находки переведены в обычные сведения.
- Белые карточки — люди, известные до текущего исследования; происхождение сведений указано у каждого факта.
- Пунктирные серые карточки — возможные родственники, родство не доказано. Переключатель «Возможные родственники» их скрывает.
- У каждого факта указаны источник и надёжность: «подтверждено документом», «вероятно», «предположение» или «со слов семьи».
- В карточке слева — фото человека. Если фото нет, там написано «фото пока нет». Фото добавляется полем `photo` в `assets/data.js`.

## Как устроено

- `index.html`, `assets/app.js`, `assets/style.css` — сайт без сборки и внешних библиотек.
- `assets/data.js` — люди, семьи, факты, места, возможные родственники, план и источники. Чтобы поправить или дополнить дерево, достаточно изменить этот файл.
- `img/` — фрагменты сканов архивных документов из открытых баз Минобороны (ОБД «Мемориал», «Память народа», «Память героев Великой войны»).

О живущих родственниках на сайте только имена.
